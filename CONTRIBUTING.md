# Contributing

This repository relates to activities in the Internet Engineering Task
Force ([IETF](https://www.ietf.org/)). All material in this repository
is considered Contributions to the IETF Standards Process, as defined in
[RFC 5378](https://rfc-editor.org/rfc/rfc5378).

Anyone can contribute to this repository. Contributions are welcome in
the form of pull requests or issues.
