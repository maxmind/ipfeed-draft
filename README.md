# ipfeed: Self-Published IP Network Metadata Format

This is the working area for the individual Internet-Draft, "ipfeed:
Self-Published IP Network Metadata Format".

- [Editor's Copy](https://maxmind.github.io/ipfeed-draft/#go.draft-phair-ipfeed.html)

## Contributing

See the
[guidelines for contributions](https://github.com/maxmind/ipfeed-draft/blob/main/CONTRIBUTING.md).

Contributions can be made by creating pull requests. The GitHub interface
can also be used for creating pull requests directly, for simple
editorial changes.

## Building the Draft

Formatted text and HTML versions of the draft can be built using
`make`.

```sh
$ make
```

Command line usage requires that you have the necessary software
installed. See [the
instructions](https://github.com/martinthomson/i-d-template/blob/main/doc/SETUP.md).
